Can an AI agent earn more than it costs? This page reads a running guard's own ledger — no demo data, no screenshots. Income counts as verified only when it came in on-chain or through Stripe; anything the agent reported itself is counted but labelled.

The guard publishes this page only when its owner turns public_pnl on and exposes it (for example with cloudflared). Every self-hosted experiment has its own guard URL — paste one above, or open the guard's own /public/pnl page directly.

Why you can believe these numbers

Verified income, honest labels.

The guard is the only process that writes the ledger, and it never writes from what the agent claims. Incoming USDC is read from the chain and Stripe sales from the Stripe API; both rows carry a verified flag, and this page shows how much of the income carries it.
