An AI agent that tries to earn more than it costs.

Cashmaxx thinks, codes, browses, and sends email like any capable agent. The difference is money: its USDC wallet sits behind a separate guard that holds the keys, enforces your budget, and asks you before anything unusual happens.

What makes it different

A capable agent, with money it can't run off with.

Cashmaxx is built on the open-source nanobot agent. It adds a wallet, a guard, and the rules that keep an honest business experiment honest.

A guard that holds the keys

The agent never sees wallet, payment, email, or social credentials. It asks a separate guard process, which checks your rules and does the work.

Approvals on your terms

Payments above your limit, or to a new recipient, wait for you in the WebUI or the guard's own Telegram bot. Both read the same queue.

Kill switch

Anyone, the agent included, can freeze all spending instantly. Only you can unfreeze it, with your PIN.

Honest P&L

Sales, x402 income, bounties, payments out, and OpenRouter compute are all tracked. Income is verified from the chain and Stripe.

Sandboxed shell

The agent's shell runs in an OS sandbox (Seatbelt on macOS, bubblewrap on Linux), so it can't read the guard's secrets.

Self-hosted, all of it

Everything runs on your machine with your own accounts. There's no Cashmaxx cloud and nothing to sign up for.

How it tries to make money

Four methods. Honest expectations.

You choose which are allowed. Each comes with a skill that tells the agent how to do it honestly, and the agent pays for its own compute from the budget.

MethodWhat the agent doesHonest expectation
Digital productsFinds real demand, builds a template, guide, or starter kit, and sells it through a Stripe payment link.The likeliest to earn something. Distribution is the hard part.
BountiesFixes small paid GitHub issues with tests and opens a PR after your review.Real payouts, heavy competition.
Paid APIs (x402)Builds a tiny pay-per-call API that other agents pay for in USDC.Paid agent traffic is still small. A long shot.
Agent marketplacesTakes paid tasks on agent job boards, after checking the platform is real.Young platforms. Treat as a gamble.

Safety model

Limits that hold even if the model misbehaves.

Budget, per-payment threshold, daily cap, hourly rate, new-recipient approval, and a loss stop are enforced by the guard, not by prompts. Every spend carries an idempotency key, so retries never pay twice.

Payments over your limit wait here, and in Telegram, until you approve them with your PIN.

Quick start

Try it with a fake wallet first.

# get the code and install
$ git clone https://github.com/tashfeenahmed/cashmaxx.git
$ cd cashmaxx && uv venv && source .venv/bin/activate
$ uv pip install -e ".[cashmaxx]"
$ (cd webui && bun install && bun run build)

# budget, network, model, rules, PIN
$ cashmaxx onboard

# two terminals
$ cashmaxx guard
$ nanobot gateway   # → http://127.0.0.1:8765
  1. Needs macOS or Linux, Python 3.11+, Bun or Node.js, and an OpenRouter key.
  2. Start on fake, a simulated wallet that moves no real money.
  3. Then base-sepolia, with free test USDC.
  4. Only then base, with real USDC and a small budget.

Experimental software, real money

Most money-making attempts by autonomous agents lose money or break even. Keep the budget small, read the safety model before funding a real wallet, and only give the agent money you can afford to lose. Cashmaxx is not financial advice.
