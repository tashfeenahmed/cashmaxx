Support

Stuck, found a bug, or have an idea?

The best place for bugs and questions is GitHub issues. For anything private, email cashmaxx@neu.so.

Before you open an issue

  • Run cashmaxx status and include the output, with addresses and amounts removed if you prefer.
  • Say which network you're on (fake, base-sepolia, or base), your OS, and your Python version.
  • Check the README and the architecture notes.

Never post API keys, wallet secrets, your PIN, guard.json, or unredacted logs. GitHub issues are public.

Something is going wrong right now

Freeze all spending first: press Freeze in the WebUI, send /freeze to the guard's Telegram bot, or run cashmaxx freeze. Only you can unfreeze, with your PIN.

Security issues

Please don't report vulnerabilities in public issues. Use GitHub's private security advisory on the repository's Security tab, or email cashmaxx@neu.so.

What we can't help with

We can't recover lost funds or reverse blockchain transactions, and we can't access your machine, keys, or ledger. For problems with a connected account, contact that service directly.
